# Reference: Instagram Analysis Output Template

> On-demand reference. Read only when producing a single-account IG analysis.
> Worked examples: `reports/audit-26.md`, `reports/audit-27.md`.

```markdown
# Instagram Analysis — @handle
_Business unit: [BotLogix | BoxBuddy | AEC Benefits] · Window: [30 days] · Date: [YYYY-MM-DD]_

## Summary
[3–5 sentences: who this account is, how it's doing, the single biggest opportunity.]

## Top 3 Action Items
1. [Specific, metric-aware action]
2. [...]
3. [...]

## Raw Data
> Source of truth. Do not mix interpretation in here. Keep links.
- Followers / following / posts: [n / n / n] (source: [link])
- Posting cadence: [x posts/week]
- Format mix: posts [n] · reels [n] · carousels [n] · stories [n]
- Engagement by format: [avg likes/comments/saves per format]
- Top posts: [link — why it worked, raw numbers]

## Observations
- [What the data shows — neutral, factual]
- [Format/timing/topic patterns]

## Recommendations
- [Interpretation and advice, anchored to the observations above]

## Open Questions / [TO CONFIRM]
- [Anything unverified or missing data]
```

## Rules
- Raw Data and Recommendations are always separate sections.
- Advice must be metric-aware (see thirty-day-success-meter-reference.md).
- Mark uncertain findings `[TO CONFIRM]`. Preserve source links.
