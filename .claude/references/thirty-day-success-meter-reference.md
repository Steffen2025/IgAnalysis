# Reference: 30-Day Success Meter

> On-demand reference. Read only when measuring 30-day progress or writing a delta.

## Purpose
A simple, repeatable way to judge whether an account improved over a 30-day
window — the basis for the "30-Day Delta System" premium module.

## Capture at day 0 and day 30 (raw)
| Metric | Day 0 | Day 30 | Δ |
|--------|-------|--------|---|
| Followers | | | |
| Posts published | | | |
| Posting cadence (/wk) | | | |
| Avg engagement / post | | | |
| Avg saves (carousels) | | | |
| Best format | | | |

## Reading the meter
- **Cadence**: compare to the account's market, not a fixed target. Never advise
  "post more" to an account already posting above its competitive set.
- **Engagement**: weight saves/shares for carousels, watch-through for reels.
- **Progress verdict**: improving / flat / declining, with the one metric that
  moved most.

## Rules
- Day-0 and Day-30 numbers are raw data; the verdict is interpretation — keep
  them separate. Mark missing baselines `[TO CONFIRM]`.
