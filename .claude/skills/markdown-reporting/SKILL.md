# Skill: Markdown Reporting

## Purpose
Assemble analysis findings into a clean, useful markdown report — the default
deliverable for this project.

## When to use
When turning collected IG/competitor data into a shareable report. Use before
any designed/PDF/Marp output is considered.

## Required inputs
- The raw data and findings for the account(s)/business unit.
- The report type (single account, competitor set, 30-day delta).

## Process
1. Pick the matching structure from the report-format reference.
2. Lead with a short summary and the top 3 action items.
3. Keep a labeled raw-data section separate from recommendations.
4. Preserve source links. Mark uncertain items `[TO CONFIRM]`.
5. Keep it useful before pretty — no designed output unless asked.

## Output format
Structured markdown only. Follow `.claude/references/report-format-reference.md`.

## Quality rules
- Action items are specific and metric-aware, not generic strategy.
- Raw data never mixed into recommendations.
- Practical, direct, human BotLogix language. No hype.
- Do not generate designed/PDF reports until the markdown logic is proven.
