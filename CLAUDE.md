## How to Work

- Read `MEMORY.md` and `AGENTS.md` at session start.
- Use `memory/projects/botlogix-ig-analysis.md` for project-specific context.
- Keep active context lean.
- Do not load large reference files unless the task requires them.
- Before major work, state which memory, skill, and reference files are needed.
- Default output is structured markdown.
- Do not create designed reports unless explicitly requested.
- Do not analyze every competitor at once.
- Start with the selected 5 accounts per business unit.
- Preserve raw data separately from recommendations.
- Prioritize clear action items over generic strategy.
- Use practical, direct, human BotLogix language.
- Avoid hype.
- Do not commit changes to git unless asked.

## Boundaries

- Do not change application source code (`src/`) without explicit approval.
- Do not expose, move, print, or alter secrets, API keys, tokens, cookies, or
  `.env` values.
- Do not modify global Claude folders without explicit approval.
