## M3 Build + Validated Live (after green light "m3")

Built the full **text-intelligence** milestone and validated it end-to-end on teardown #1
(cooper.simson):

- **LLM tasks** — extended `llmClient.LlmTask` with `teardown_caption_system`,
  `teardown_comment_drivers`, `teardown_success_thesis` (thesis routed as SMART → mini model).
- **Deterministic analyzers** (new in `src/services/teardown/`):
  - `metrics.ts` — avg/median likes/comments/plays, engagement rate, posting cadence, format-mix,
    recent-vs-prior-half momentum, top-N tables, viral outliers (≥2.5× median).
  - `captionAnalysis.ts` — caption length, question/number hooks, common openers, CTA mix,
    "comment KEYWORD" triggers, emoji usage, CTA→comment lift, exemplars.
  - `hashtagTeardown.ts` — per-post count + assessment, core reused set (≥40%), top tags, top pairs.
  - `commentDrivers.ts` — question/tag/emoji rates, short-reply rate, **keyword-echo** rate, top tokens.
- **Comment capture** — `teardownComments.ts` scrapes top-N posts by comment volume; idempotent,
  cached, budget-gated (`TEARDOWN_MAX_RUNS` default raised to 24, `TEARDOWN_COMMENTS_PER_POST=30`).
- **LLM synthesis** — `teardownPrompts.ts` (registry, deterministic-facts-only, never-fabricate);
  `analysisRunner.ts` runs comments → analyzers → 3 LLM tasks (with validators + fallback) →
  `markdownReport.ts` assembles the full structured `report.md` (spec §11; honest "not generated"
  notes when a key/task is missing).
- **Orchestrator** — `DATA_EXPORTED` now runs analysis (gated by `TEARDOWN_RUN_ANALYSIS`, default on)
  then `COMPLETE`; analysis failure is caught as a partial flag, never discards the M1 capture.
- **CLI** — `npm run teardown:analyze <id|latest> [--no-comments]` re-runs analysis without re-scraping.

**Live validation (teardown #1):** 295 comments captured across top 12 posts, 3/3 LLM calls OK

CTAs, 1.85 comment-to-like ratio, 39% keyword-echo, honest DOWN -58% within-window momentum.
